Self-hosted font assets

These are unmodified WOFF2 subsets from the Google Fonts stylesheet used by this homepage:
https://fonts.googleapis.com/css2?family=DM+Sans:wght@300;400;500;600;700&family=Oswald:wght@400;500;600;700&display=swap

Retrieved 2026-10-10. Oswald v57 and DM Sans v17 preserve the existing font families, requested weight ranges and Unicode subsets. Only the Latin subsets are preloaded; other subsets are requested only for matching text. Font-face declarations are in src/fonts.css.
